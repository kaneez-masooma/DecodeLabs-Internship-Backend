# Decode Labs - Task Manager Backend

## 📌 Project Overview
This backend handles API functionality for the Task Manager application developed during Decode Labs internship.

## 🎯 Features
- Create tasks API
- Get all tasks API
- Delete tasks API
- Update task status (complete/pending)

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB (or in-memory array if simple)

## 🚀 How to Run
1. Install dependencies:
   npm install

2. Start server:
   node server.js

3. Server runs on:
   http://localhost:3000

## 📡 API Endpoints
- GET /tasks
- POST /tasks
- DELETE /tasks/:id
- PUT /tasks/:id
